## Featured Projects

### AI Proctoring System
AI-powered online exam proctoring platform that flags suspicious behavior in real time using computer vision.

**Problem solved** — Remote exams have no reliable way to detect cheating without a human invigilator watching every feed live. This automates that monitoring layer.

**Stack** — React, Vite, Tailwind CSS, Flask, Python, OpenCV, YOLO, MongoDB

**Key features**
- Face verification at exam start
- Multiple-face and phone detection
- Suspicious movement & head-pose analysis
- Tab-switch / full-screen exit monitoring
- Full exam event logging for review
